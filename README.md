🎛 Подкрутка шансов (админка)
В админ-панели → Подкрутка можно установить:

Winrate 0–100% — влияет на все игры

Payout mult 0.0–10.0 — множитель выплат

Как работает
Значение	Эффект
winrate = 50	Честная игра
winrate = 100	Игрок всегда выигрывает
winrate = 0.01	Игрок всегда проигрывает (во всех играх)
payout_mult = 0.5	Выплаты уменьшены в 2 раза
payout_mult = 2.0	Выплаты увеличены в 2 раза
Где работает подкрутка при winrate < 1%
Crash — мгновенный краш на ×1.00

Plinko — всегда слот с ×0

Dice — всегда промах

Coin — всегда противоположная сторона

Mines — первая клетка всегда мина

Slots 5×3 — выигрыш обнуляется

Upgrader — всегда луз

Cases — всегда common-предмет

Duel — игрок всегда проигрывает

Работает как глобально (для всех), так и для конкретного юзера (по ID или @username).

📊 RTP (Return to Player)
По умолчанию:

Кейсы: ~55% (при RARITY_TABLE из коробки)

Апгрейдер: ~30–40% (из-за HOUSE_EDGE = 0.35)

Игры (Crash, Dice, Coin): ~95–97%

RTP можно изменить через RARITY_TABLE в main.py и через админку.

🐛 Возможные проблемы
Бот не запускается
Проверь:

BOT_TOKEN правильно указан в .env

Python 3.11+ установлен

Все зависимости установлены (pip install -r requirements.txt)

Порт 8000 не занят другим процессом

Mini App не открывается
Проверь:

WEBAPP_URL указывает на работающий сервер

HTTPS обязателен для Mini App

Сертификат SSL валиден

Ошибка IndentationError
Файлы повреждены. Загрузи свежую копию из архива.

База данных не создаётся
Проверь права на запись в директорию проекта.

Telegram Stars не работают
Убедись, что бот подключён к платежам в @BotFather

Проверь currency="XTR" в create_invoice_link

USDC не зачисляется
Проверь SELLER_WALLET в .env

Проверь POLYGONSCAN_API_KEY

Убедись, что отправлена ровно та сумма, которую показал бот
